# ARIA - AI Operating System

A futuristic, web-based AI Operating System with voice commands, task management, and marketing automation capabilities.

## Features

✨ **Futuristic UI**
- Glassmorphism design
- Smooth animations & transitions
- Responsive layout

🎤 **Voice Commands**
- Real-time speech recognition
- Natural language processing
- Instant voice feedback

📋 **Task Management**
- Create, update, and delete tasks
- Priority and status tracking
- Due date management

📊 **Marketing Hub**
- Campaign tracking
- Performance analytics
- Engagement metrics

## Quick Start

```bash
# Clone the repo
git clone https://github.com/kshitijnanda8-ui/aria-os.git
cd aria-os

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
aria-os/
├── src/
│   ├── components/        # React components
│   ├── store/            # Zustand state management
│   ├── App.jsx           # Main app component
│   ├── main.jsx          # Entry point

```

## Voice Commands

- "add task [task name]" - Create a new task
- "hello" - System greeting
- Any other command - Acknowledged and logged

## Built With

- **React 18** - UI framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Zustand** - State management
- **Web Speech API** - Voice recognition
